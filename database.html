Database Architecture & SQL Development

This project showcases comprehensive skills in relational database design, data normalization, and complex querying. It involves designing databases from scratch for various real-world scenarios and analyzing large-scale datasets.

Database Design & Normalization

  • Created detailed Entity-Relationship Models (ERM) using Chen and MC notations to map out complex architectures for systems such as a Q&A platform (StackOverflow clone), a Student Information System, and a tech support management tool.
  • Translated ERMs into efficient Relational Models (RM), rigorously applying normalization rules up to the Third Normal Form (3NF) to eliminate data redundancy and anomalies.
  • Implemented the logical designs using SQL Data Definition Language (DDL), defining robust data types, primary/foreign keys, and specific constraints.

Advanced Data Analysis & Querying (DQL)

  • Executed advanced SQL queries (DQL) to extract insights from extensive datasets, including global flight logistics, UN population/energy statistics, and Olympic game records.
  • Utilized complex SQL functions, including advanced aggregations, mathematical ranking functions, and cross joins to analyze data quality and verify system integrity.

Database Programming

  • Developed and deployed database triggers using DDL to automate backend processes, enforce business rules, and maintain strict data integrity upon insertion or deletion events.
