Wheatstone Bridge Calibration & DAQ

In this project, I implemented a strain gauge-based measurement system using a Wheatstone Bridge configuration and National Instruments LabVIEW software for real-time data acquisition and processing.

Hardware Setup & Calibration

The system utilizes a bending beam equipped with four strain gauges in a full-bridge arrangement, powered by a 6V supply. Initial measurements were conducted using a multimeter and an oscilloscope to observe voltage values and instrument response. The bridge was manually balanced using a resistor decade, fine-tuning the sensitivity to E0 = 1 mV/100g.

Data Acquisition & Processing

Following hardware calibration, an NI-DAQ device was integrated to enable differential voltage measurements via LabVIEW. Software calibration was implemented to compensate for supply voltage fluctuations and hardware adjustments. The final system successfully verified the linear behavior of the bridge voltage with respect to applied weight changes.
