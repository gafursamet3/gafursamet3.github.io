SiparisID - POS & Cafe Management System

SiparisID is a comprehensive Point of Sale (POS) and cafe management web application designed to streamline restaurant operations. Built with a React frontend and a Node.js backend, the system demonstrates advanced state management, real-time UI interactions, and practical business logic execution.

Key Features & Architecture

  • Dynamic Table Management: Engineered an interactive floor plan utilizing HTML5 drag-and-drop APIs, allowing administrators to position and resize tables in real-time.
  • Order Processing & KDS: Developed a robust order routing system that separates bar and kitchen items, featuring a dedicated Kitchen Display System (KDS) for back-of-house staff.
  • Financial Operations: Implemented complex payment logic supporting split payments, dynamic discount application, cover charges, and automated X/Z-Report generation for shift tracking.
  • Hardware Integration: Configured precise CSS print media queries to format and generate thermal printer-ready receipts directly from the browser.
